# Decisions

1. **Public name "Hum & Bell".** "Transcendental Meditation" and "TM" are trademarks (the brief's risk list); the site never uses them except to state non-affiliation. "Stillroom" was considered but its .com/.org/.app are taken. The repository keeps its assigned working name, which does appear in the github.io URL: a custom domain fixes that (OPERATIONS.md key 1).
2. **Synthesis, not "AI music".** A Web Audio drone, noise and bells, generated live, sound good, cost nothing, and need no model or server. "Generated" means composed per session from a seed.
3. **A written guidance library instead of runtime AI.** 229 plain, secular lines across eight widely taught practices, drawn by a seeded planner so sessions vary but links replay exactly. Pre-written per the brief (no API key in Actions); a content routine can extend it.
4. **No health claims, enforced by tests.** The guidance and practice content are scanned for clinical and outcome words. The binaural page cites a 2023 systematic review showing inconsistent evidence and offers the tone only as a sound.
5. **Browser voices, local first.** Text-to-speech needs no files; captions always show (some devices have no voices). Online voices are labelled, since they send the guidance text to the browser maker.
6. **Standalone, not a BUMP genre.** The evaluator suggested folding this into another product; that needs Jack's other systems. A standalone free tool ships now and can be embedded later.
7. **Word repetition with the user's own word.** A common contemplative practice, explicitly not the TM technique (which assigns personal mantras through teachers).
